# 🎨 1440x3440.com Icon History

이 폴더는 앱이 발전하면서 거쳐간 모든 앱 아이콘 디자인(PNG 원본 파일)을 차곡차곡 보관하는 **디자인 아카이브(Archive)** 입니다.

- 나중에 이전 감성으로 돌아가고 싶을 때 언제든 원본을 꺼내 쓸 수 있습니다.
- 새로운 아이콘을 추가할 때는 `icon_v[버전]_[컨셉이름].png` 형식으로 저장해 두면 관리하기 좋습니다.
